# 概要と設計の考え方

このリポジトリでは、制御系の実装を「機能ごとに小さなクラスとして組み立てる」ことを重視しています。
たとえば、PID 制御、Kalman Filter、線形回帰のような要素は、それぞれ独立したクラスとして提供され、サンプルコードではそのクラスを組み合わせて動作を確認します。

## 1. どのクラスが何をするか

| 目的 | 主なクラス | 典型的な例 |
|---|---|---|
| 制御入力を自動計算したい | `DiscretePID_Controller` | サーボモータの角度制御 |
| 線形システムの状態を推定したい | `LinearKalmanFilter` | 連続時間系を離散化した状態推定 |
| 非線形システムを推定したい | `ExtendedKalmanFilter` | 自動運転の車両状態推定 |
| 非線形かつ高次の分布推定が必要 | `UnscentedKalmanFilter` | 車両・移動体の複雑な推定 |
| 既存データから係数を決めたい | `LeastSquares` | 回帰モデルの作成 |
| 逐次に係数を更新したい | `RecursiveLeastSquares` | オンライン識別 |

## 2. サンプルコードの見方

サンプルスクリプトでは、以下の順で処理を進めることが多いです。

1. モデルやシステムを定義する
2. クラスのインスタンスを作る
3. ループまたは1回の更新でデータを入力する
4. 出力や推定状態を確認する
5. 可視化ツールで結果を見る

```mermaid
flowchart LR
    A[モデル定義] --> B[クラス生成]
    B --> C[更新 or 学習]
    C --> D[推定結果 / 出力]
    D --> E[可視化]
```

## 3. 使い方の基本パターン

### PID

- 目標値と現在値との差を計算する
- `update(error)` にその差を渡す
- 出力制限 (`minimum_output`, `maximum_output`) を設定する

### Kalman Filter

- 状態遷移の行列や関数を定義する
- `predict(...)` で予測を進める
- `update(...)` で観測値を反映する
- `get_x_hat_without_delay()` で遅れを考慮しない推定状態を確認する

### 最小二乗

- `fit(X, y)` で重みを計算する
- `predict(X)` で未学習データを予測する
- `get_weights()` で学習済みパラメータを確認する

## 4. 実例の位置づけ

- `sample/pid_controller/*.py` は、制御入力の計算を何回も繰り返す利用方法を示します。
- `sample/kalman_filter/*.py` は、状態推定を行うクラスの作法を見せます。
- `sample/least_squares/*.py` は、モデルを学習して予測する方法を示します。

このドキュメントでは、特に「クラスをどのように使うべきか」に注目して説明します。内部計算の厳密な導出よりも、どのタイミングで何を渡し、何を受け取るかを順番に見ていきます。
